# CorkAssessment
This is a repo designed to hold the Cork 2025 Summer Intern coding assessment

### Start Time: 7:22 pm EDT
### End Time: 8:55 pm EDT

For this assessment, I did some research to see what tech stack would be best for this kind of smaller program. <br>
Though I have experience in PostgreSQL and Flask, I decided to take this opportunity to try out FastAPI and SQLite as mentioned within the assessment. <br>
This application's tech stack is comprised of the FastAPI framework for backend CRUD based operations, with a SQLite database for a smaller, less industrial need.

# How to run
1. Clone the repository:
    ```
    git clone _repositoryUrl_
    cd CorkAssessment

2. Run a virtual environment:
    ```
    python -m venv venv
    source venv/bin/activate

3. Run installation of dependencies:
    ```
    pip install -r requirements.txt

4. Run the application via terminal:
    ```
    uvicorn main.app --reload

5. Open browser:
    ```
    Copy link given in terminal
